# Les lumières Philips Hue

## Ce que font les lumières

Les ampoules de la pièce suivent le déroulé de la partie, automatiquement :

| Moment | Ambiance |
|--------|----------|
| Accueil des joueurs | Lumière d'attente |
| Élection du maire | Ambiance solennelle |
| Cupidon | Rose |
| Sœurs jumelles | Magenta tendre qui pulse |
| Salvateur | Bleu turquoise |
| Les Loups chassent | Rouge |
| Voyante | Violet |
| Sorcière | Vert |
| Le jour | Doré |
| Évènements du Conseil des Morts | Une ambiance propre à chacun des 18 évènements (orage, brouillard, incendie…) |
| Pause | Lumière presque éteinte |

Et des **flashs** aux moments forts : une mort, une aube sans victime (lumière dorée douce), les loups qui choisissent leur proie, l'Idiot démasqué, la cloche du maire, la victoire.

Si les lumières ne répondent pas (bridge éteint, mauvais réseau…), **le jeu continue normalement** : elles ne peuvent jamais bloquer ou faire planter une partie.

## Matériel

- Un **Bridge Philips Hue** (le petit boîtier blanc), branché **en câble** sur la box ou le routeur — plus fiable qu'en Wi-Fi.
- Des **ampoules Hue couleur** (« White and Color Ambiance »). Les ampoules blanches seules ne rendront pas les couleurs.
- Dans l'application Hue du téléphone : une **pièce nommée « Loup-Garou »** qui regroupe les ampoules à piloter. Le jeu ne touche qu'à cette pièce.

## État actuel

Les lumières sont **déjà configurées et activées** sur ton ordinateur.

## Vérifier que ça marche

Double-clique sur **`Tester les lumieres.bat`** (dans ce dossier). Une fenêtre affiche la configuration et envoie une commande au Bridge : si tes ampoules réagissent et que le message est positif, tout est bon.

Autre façon : lance une partie avec des bots (voir la fiche mise en place) et regarde les couleurs changer.

## Quand il faut demander à Claude

Ces réglages se font dans le code — dis simplement à Claude ce que tu veux :

- **Nouveau Bridge, nouvelle maison ou nouveau réseau** (l'adresse du Bridge change) : « reconfigure les lumières Hue ». Il faudra appuyer sur le **bouton rond du Bridge** au moment où il te le demande (le Bridge n'accepte un nouvel appareil que dans les 30 secondes qui suivent l'appui).
- **Désactiver ou réactiver** les lumières.
- **Changer une couleur ou une ambiance** (« je veux la nuit des loups plus sombre », « l'aube trop jaune »…).
- **Changer de pièce** dans l'application Hue.

## Conseils pour une soirée

- Éteins les autres lumières de la pièce (ou garde une petite lampe non connectée) : l'effet est bien plus fort dans le noir.
- Évite que les ampoules connectées soient trop près des joueurs qui doivent garder les yeux fermés : un flash rouge très proche peut se voir à travers les paupières… et trahir le moment où les loups agissent.
- Pour un kit à emporter : Bridge + 2 ou 3 ampoules couleur dans des lampes d'appoint, branchés sur le routeur de voyage (voir la fiche mise en place, « Jouer ailleurs que chez soi »).
